
# Mobility Insights Dashboard – Streamlit

Many mobility teams face the same key questions every day:

* Where should we place supply?
* When will demand spike?
* Which product mix lifts margin without hurting user experience? 🤔

To explore these questions end-to-end, this project introduces a **Mobility Insights Dashboard** built with **Streamlit**, powered by **150,000 real Uber rides across India**.

The dashboard connects **data exploration → operational diagnosis → business prediction** in one simple, visual story. 🔍➡️📈

---

## 🔑 Key Insights

### 🗺️ Demand Patterns

Clear **hour × zone** trends help reveal when and where to pre-position drivers.

### ⚠️ Operational Performance

* VTAT/ETA and cancellation signals highlight when performance starts slipping.

### 🚗 Product & Payment Mix

* Mix insights (2-wheel vs 4-wheel, UPI/Wallet vs Cash) show how small shifts can rebalance **growth** and **margin**.

### 🧠 ML Layer

A lightweight **Lasso regression** estimates **booking value** and quantifies key revenue drivers.

---

## 📊 Business Impact

At dataset scale, these micro-levers translate into an estimated **+$12K to +$24K per year** through:

* Better matching
* Smarter upsells
* Steadier payment behavior
